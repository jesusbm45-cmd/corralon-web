# cdoncoco.com · página temporal

Mientras se termina la web nueva, el sitio muestra una sola página: "Estamos construyendo la nueva web", con una obra en 3D (albañiles que llevan bloques de código que se vuelven ladrillos al asentarse), WhatsApp, dirección, horarios y redes.

- `index.html` es la página completa: estilos y la escena 3D van dentro del mismo archivo. Usa Three.js 0.160.0 (jsDelivr), GSAP 3.12.5 (cdnjs) y fuentes de Google.
- Si el 3D no carga, se muestra la casita dibujada. Con "reducir movimiento" la obra queda quieta. En equipos lentos baja sola la definición y saca las sombras.
- El aviso de Black Coco se oculta solo desde el 29/11 (`data-hasta`).
- La web nueva (inicio, Club Don Coco, Jadever y Black Coco) no está en esta rama para que no quede pública. Está guardada en el Drive, en "10 · Sitio web".
- Hostinger publica la rama `main` sola en cada push. No hacer push a `main` sin que lo pida Jesús.
